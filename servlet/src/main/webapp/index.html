Servlet Learning Project

Dự án học tập Java Servlet với các ví dụ thực hành.
Mỗi ví dụ minh họa một khái niệm quan trọng trong Servlet API.

👋

Hello Servlet

Servlet cơ bản nhất. Xử lý GET request, đọc query parameters, hiển thị thông tin request.

GET Query Params Response
GET /hello?name=YourName
📝

Form Servlet

Xử lý HTML form. So sánh GET vs POST, đọc form data, hiển thị kết quả.

GET POST Form Data
GET/POST /form
🔐

Session Servlet

Quản lý HTTP Session. Đếm lượt truy cập, lưu/đọc dữ liệu session, hủy session.

HttpSession Cookies State
GET/POST /session
🔄

Lifecycle Servlet

Vòng đời Servlet: Constructor → init() → service() → destroy(). Singleton pattern.

Lifecycle Singleton init/destroy
GET /lifecycle
🔌

REST API Servlet

REST API trả về JSON. CRUD operations cho Todo list. Dùng Gson cho JSON.

REST API JSON CRUD
GET/POST/DELETE /api/todos
🔍

Logging Filter

Filter chạy tự động trên MỌI request. Xem terminal/console để thấy log output.

Filter Middleware Logging
Áp dụng cho /* (tất cả URL)

🏗️ Kiến trúc dự án

servlet/
├── pom.xml                          ← Maven config (dependencies)
├── README.md                        ← Tài liệu giải thích
└── src/main/
    ├── java/com/learn/servlet/
    │   ├── HelloServlet.java        ← GET request cơ bản
    │   ├── FormServlet.java         ← Xử lý form (GET/POST)
    │   ├── SessionServlet.java      ← Quản lý session
    │   ├── LifecycleServlet.java    ← Vòng đời servlet
    │   ├── ApiServlet.java          ← REST API (JSON)
    │   └── filter/
    │       └── LoggingFilter.java   ← Filter (middleware)
    └── webapp/
        ├── WEB-INF/
        │   └── web.xml              ← Deployment Descriptor
        ├── index.html               ← Trang chủ (file này)
        ├── api-test.html            ← Giao diện test API
        ├── css/style.css            ← Stylesheet
        └── error/
            ├── 404.html             ← Trang lỗi 404
            └── 500.html             ← Trang lỗi 500
